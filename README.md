Getting Started
1. Clone Repository
git clone https://github.com/dotin2001/NextJs_Mini_Blog.git
2. Install Dependencies

Using npm:

npm install

Using pnpm:

pnpm install
3. Run Development Server
npm run dev

or

pnpm dev
4. Open Browser
http://localhost:3000
Environment Variables

Create:

.env.local

Example:

NEXT_PUBLIC_APP_URL=http://localhost:3000
Scripts
npm run dev
npm run build
npm run start
npm run lint
